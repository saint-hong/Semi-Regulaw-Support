핵심 기능 흐름
--------------
[로그인] login.html
  → POST /api/v1/auth/login
  → JWT 발급 (tenant_id + department + permissions 포함)
  → localStorage 저장 → index.html 리다이렉트

[규제 분석] index.html (영업부, 법률지원부, admin만 접근)
  → POST /api/v1/analyze + Bearer 토큰
  → Claude AI 분석 → 탭 기반 리포트 표시

[출하 워크플로우] (영업부 ↔ 로지스틱부)
  PENDING → SALES_APPROVED → LOGISTICS_DONE → FINAL_APPROVED

API 엔드포인트
--------------
GET  /api/v1/health                           # 서버 상태
POST /api/v1/auth/login                       # 로그인 → JWT 반환
POST /api/v1/auth/register                    # 회원가입
GET  /api/v1/auth/me                          # 현재 사용자 정보
POST /api/v1/analyze                          # BOM 규제 분석 (Claude AI)
POST /api/v1/shipments                        # 출하 요청 생성
GET  /api/v1/shipments                        # 출하 목록 조회
PATCH /api/v1/shipments/{id}/approve          # 영업부 출하 승인
PATCH /api/v1/shipments/{id}/logistics-done   # 로지스틱부 선적 완료 보고
PATCH /api/v1/shipments/{id}/final-approve    # 영업부 최종 확인
