## 2. UI 개선 핵심 전략 (Action Plan)

### A. 디자인 시스템의 '산업적(Industrial)' 전환
- **Color:** 신뢰감을 주는 Deep Navy (#1A202C)와 Slate Grey 메인 테마 적용.
- **Typography:** 수치 및 코드 데이터에 Mono-space 폰트 적용 (정밀 데이터 느낌 강조).
- **Style:** 둥근 모서리 반경을 줄이고(SaaS → Enterprise), Sharp한 UI 컴포넌트 사용.

### B. 레이아웃 고도화 (Expert Layout)
- **대시보드:** 단순 카드 위주에서 Chart.js/D3.js를 활용한 통계적 시각화로 변경.
- **분석 화면:** '입력부(Step 1~4)'와 '결과 리포트'를 2분할 레이아웃으로 최적화하여 비교 가시성 확보.
- **Report Preview:** 실제 규제 보고서(PDF) 포맷과 유사한 위지윅(WYSIWYG) 스타일 리포트 UI 도입.

### C. 엔터프라이즈 보안 및 신뢰성 강화
- **보안 라벨:** 화면 상단/하단에 `[CONFIDENTIAL / INTERNAL ONLY]` 및 테넌트 식별자 명시.
- **XAI (Explainable AI):** 규제 위반 항목 발생 시, 실제 법률 조항(EAR 등)의 임계값과 제품 스펙을 시각적 테이블로 1:1 대조.
- **Audit Trail:** 컴플라이언스 팀을 위한 '누가, 언제, 어떤 기준으로 승인했는지'에 대한 이력 뷰어 강화.

## 3. 향후 구현 로직 반영 사항 (Summary Reference)

본 UI 개선은 다음의 기존 설계 방향을 계승함:
- **`gemini_summary_1.txt`**: 부서별(영업/물류/법률) 특화 메뉴 및 KYC 스크리닝 기능.
- **`regulatory_analysis_design.txt`**: 상세 BOM 입력 필드(Node, Spec, ECCN 등)와 동적 피드백 시스템.

---
**결론:** 본 개선안은 단순히 '예쁜 UI'를 만드는 것이 아니라, 삼성/하이닉스 실무자가 **"이 시스템은 우리 업무의 리스크를 완벽하게 통제하고 있다"**는 확신을 갖게 하는 데 목적이 있음.
